## Åpne beslutninger

Disse må avklares før tilbudet kan ferdigstilles. Se `01_STRATEGI.md` for anbefalinger.

1. **Bemanning** — hvem er utvikler nummer to? Ansettelse, innleie eller underleverandør.
2. **Språk i tilbudet** — anbefaling: norsk hoveddokument, engelsk sammendrag.
3. **Prisnivå** — se `05_PRISMODELL.md`, krever en beslutning om posisjonering.
4. **Kontakt med NFIF før frist** — anbefaling: be om avklaringsmøte umiddelbart.
