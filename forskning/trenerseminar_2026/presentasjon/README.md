# Presentasjon: Har bredde noe å si for topp?

Kildefilene til foredraget på Trenerseminaret 2026 (36 slides, Fagnytt-design).

- Lysbildene ligger på https://claude.ai/artifact/1kbXaMCVwV7nbqYTS2dZok (privat til den deles).
  Der kan de redigeres, vises i «Present», og lastes ned som PowerPoint eller PDF fra Share › Export.
- `deck.json` er rekkefølgen og seksjonene, `slides/*.html` er én fil per slide, med talemanus i `<aside>`.
- Figurene i slidene peker på opplastede kopier av filene i `forskning/fagnytt/figurer/` og
  `analyse/trenerartikkel/output/`.
- Manus og slide-for-slide-plan: `../foredrag_plan.md`.
